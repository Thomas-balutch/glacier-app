Données glaciaires

Les données utilisées pour la cartographie et l'évolution des glaciers proviennent de bases scientifiques internationales.

  • GLIMS — Global Land Ice Measurements from Space
  • WGMS — World Glacier Monitoring Service
  • ESA Climate Change Initiative

Données faune alpine

Les informations concernant les espèces alpines menacées sont basées sur des données issues de la littérature scientifique et de bases de données de conservation.

  • IUCN Red List
  • Muséum National d'Histoire Naturelle
  • Parcs naturels alpins

Technologies utilisées

  • HTML / CSS / JavaScript
  • Leaflet (cartographie interactive)
  • Chart.js (visualisation des données)

Objectif du projet

Ce site est un projet pédagogique visant à rendre les données scientifiques sur les glaciers alpins accessibles au grand public et à sensibiliser aux impacts du changement climatique.
