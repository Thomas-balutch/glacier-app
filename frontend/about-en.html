The project

This website is an educational platform dedicated to Alpine glaciers. It allows users to visualize their location, their evolution and the impacts of climate change.

Data sources

Glacier data come from scientific databases such as GLIMS and WGMS. These sources make it possible to observe the evolution of glacier surface areas over more than a century.

Technologies

The website uses modern web technologies: HTML, CSS and JavaScript. Leaflet is used for interactive mapping and Chart.js for data visualization.

Educational objective

The goal is to make scientific data about Alpine glaciers accessible to the general public and to raise awareness of the impacts of climate change on glaciers and alpine ecosystems.

Project author

This website was developed by Thomas Balutch, Linux systems administrator with a DevOps orientation and passionate about alpine environments.

A mountain enthusiast who loves high-altitude landscapes, he is particularly interested in the evolution of glaciers and the impacts of climate change on alpine ecosystems.

This personal project combines interactive mapping, data visualization and web technologies in order to make scientific information more accessible to the general public.

Project status: this website is currently in initial version (V1) and continues to evolve. New features and datasets will be progressively added.
